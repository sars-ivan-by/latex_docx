План развития

Что уже есть в 0.2.0 и что имеет смысл делать дальше. Это не срок следующего релиза. Тот же план в репозитории — файл ROADMAP.md.

Уже есть

  • Типичная статья LaTeX собирается в DOCX по требованиям TD-J. Формулы становятся формулами Word, если установлено дополнение omml.
  • Короткий Markdown идёт в тот же сборщик DOCX.
  • Markdown собирается в PowerPoint. Файл организации .pptx задаёт размер, тему и макеты.
  • PDF — это тот же DOCX, сохранённый Microsoft Word.
  • Сравнение двух DOCX по абзацам, отчёт в Markdown.
  • Документация на английском, русском и китайском.
  • Язык ru или en в библиотеке и в командной строке. По умолчанию русский.
  • --docx-template сохраняет стили и поля файла организации .docx или .dotx.
  • Заголовки разделов — стили Word. Списки Markdown могут быть вложенными, а [^id] становится сноской Word.
  • --template article — вёрстка с одним блоком шапки, для статьи не в TD-J.

Дальше

Дальше очередь пустая. Полный перенос DOCX обратно в TeX остаётся за рамками. Правки из Word возвращаются через отчёт diff.

Не делаем

  • Замену pandoc.
  • Восстановление исходного LaTeX из произвольного DOCX.
  • Свой рендер PDF. На macOS и Windows PDF по-прежнему делает Word. На Linux его пишет LibreOffice, и страница может отличаться.
