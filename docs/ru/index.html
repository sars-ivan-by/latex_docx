latex-docx

Научная статья из LaTeX в Word, заметка из Markdown в тот же DOCX, доклад из Markdown в PowerPoint. PDF сохраняет Microsoft Word из готового DOCX, поэтому страница совпадает с документом.

Установка

pip install "latex-docx[omml,pptx]"

omml записывает формулы как формулы Word. Для слайдов нужен pptx. PDF на macOS и Windows делает Word. На Windows: pip install "latex-docx[win]". На Linux PDF пишет LibreOffice (soffice), и страница может отличаться от Word.

Командная строка

latex-docx article.tex -o out_article.docx
latex-docx notes.md -o out_notes.docx --lang en --pdf
latex-docx slides.md -o out_slides.pptx --pptx-template org.pptx
latex-docx --diff-docx out_base.docx out_edited.docx -o out_changes.md

Библиотека

from latex_docx import convert, docx_to_pdf, markdown_to_pptx

convert("notes.md", "out_notes.docx", lang="en")
docx_to_pdf("out_notes.docx")
markdown_to_pptx("slides.md", "out_slides.pptx", template="org.pptx")

Файл организации .pptx задаёт размер, тему и макеты. Слайды, которые уже лежат в этом файле, не копируются. Если имена макетов другие, передайте title_layout и content_layout.

Язык — ru (по умолчанию) или en. Шаблон tdj печатает русскую шапку, затем английскую. Шаблоны plain и article печатают один блок. --docx-template берёт стили Word организации.
