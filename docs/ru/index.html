latex-docx

Сборка DOCX, PDF и PowerPoint из Markdown или LaTeX. Агент выбирает шаблон, язык и макет слайда. Научная статья — один из шаблонов, а не весь инструмент.

Установка

macOS и Linux:

pip install "latex-docx[omml,pptx]"

Windows

Нужны Python 3.9+ с галочкой «Add python.exe to PATH» и установленный Microsoft Word, если нужен PDF. В PowerShell:

py -m pip install "latex-docx[omml,pptx,win]"

Дополнение win ставит pywin32, через него PDF сохраняет Word. В cmd то же самое, только py можно заменить на python, если он уже в PATH.

Из клона репозитория:

py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install -e ".[omml,pptx,win,dev]"

Если PowerShell не даёт запустить Activate.ps1, один раз выполните Set-ExecutionPolicy -Scope CurrentUser RemoteSigned. В cmd активация другая: .venv\Scripts\activate.bat.

omml записывает формулы как формулы Word. Для слайдов нужен pptx. На Linux PDF пишет LibreOffice (soffice), и страница может отличаться от Word.

Командная строка

latex-docx article.tex -o out_article.docx
latex-docx notes.md -o out_notes.docx --lang en --pdf
latex-docx slides.md -o out_slides.pptx --pptx-template org.pptx
latex-docx --diff-docx out_base.docx out_edited.docx -o out_changes.md

Библиотека

from latex_docx import convert, docx_to_pdf, markdown_to_pptx

convert("notes.md", "out_notes.docx", lang="en")
docx_to_pdf("out_notes.docx")
markdown_to_pptx("slides.md", "out_slides.pptx", template="org.pptx")

Файл организации .pptx задаёт размер, тему и макеты. Слайды, которые уже лежат в этом файле, не копируются. Если имена макетов другие, передайте title_layout и content_layout.

Язык — ru (по умолчанию) или en. Шаблон tdj печатает русскую шапку, затем английскую. Шаблоны plain и article печатают один блок. --docx-template берёт стили Word организации.

Слайды

Строка --- начинает следующий слайд. Один # — титульный, ## — обычный, ??? — заметки докладчика.
