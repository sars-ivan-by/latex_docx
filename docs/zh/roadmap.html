路线图

0.2.0 已经做到的，以及之后值得做的。这不是下一版的发布日期。仓库里的同一份计划是 ROADMAP.md（英文，与代码文档一致）。

已经完成

  • 常见的 LaTeX 论文可以转成符合 TD-J 要求的 Word 文件。安装 omml 附加组件后，公式写成 Word 公式。
  • 简短的 Markdown 走同一套 DOCX 生成器。
  • Markdown 可以生成 PowerPoint。单位的 .pptx 提供尺寸、主题和版式。
  • PDF 是 Microsoft Word 从这份 DOCX 另存的结果。
  • 按段落比较两份 DOCX，并写出 Markdown 报告。
  • 文档有英文、俄文和中文三套页面。
  • 库和命令行支持 ru 或 en。默认是俄文。
  • --docx-template 保留单位 .docx 或 .dotx 的样式和页面设置。
  • 章节标题使用 Word 标题样式。Markdown 列表可以嵌套，[^id] 会写成 Word 脚注。
  • --template article 是单块题头的版式，用于不是投给 TD-J 的文章。
