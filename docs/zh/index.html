latex-docx

从 Markdown 或 LaTeX 生成 DOCX、PDF 和 PowerPoint。代理选择模板、语言和幻灯片版式。科学论文只是其中一种模板。

安装

macOS 和 Linux：

pip install "latex-docx[omml,pptx]"

Windows

安装 Python 3.9 或更高版本，并勾选 “Add python.exe to PATH”。若要生成 PDF，还需要安装 Microsoft Word。在 PowerShell 中：

py -m pip install "latex-docx[omml,pptx,win]"

附加组件 win 会安装 pywin32，PDF 由 Word 写出。若 python 已在 PATH 中，在 cmd 里可以把 py 换成 python。

从仓库克隆安装：

py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install -e ".[omml,pptx,win,dev]"

若 PowerShell 拒绝运行 Activate.ps1，先执行一次 Set-ExecutionPolicy -Scope CurrentUser RemoteSigned。在 cmd 中用 .venv\Scripts\activate.bat。

omml 把公式写成 Word 公式。pptx 用于幻灯片。Linux 上由 LibreOffice（soffice）生成 PDF，页面可能与 Word 不同。

命令行

latex-docx article.tex -o out_article.docx
latex-docx notes.md -o out_notes.docx --lang en --pdf
latex-docx slides.md -o out_slides.pptx --pptx-template org.pptx
latex-docx article.tex --template article --lang en --docx-template org.docx
latex-docx --diff-docx out_base.docx out_edited.docx -o out_changes.md

库

from latex_docx import convert, docx_to_pdf, markdown_to_pptx

convert("notes.md", "out_notes.docx", lang="en")
docx_to_pdf("out_notes.docx")
markdown_to_pptx("slides.md", "out_slides.pptx", template="org.pptx")

单位的 .pptx 提供幻灯片尺寸、主题和版式。文件里原有的幻灯片不会被复制。版式名称与默认不同时，传入 title_layout 和 content_layout。

lang 为 ru（默认）或 en。模板 tdj 先写俄文题头，再写英文题头。模板 plain 和 article 只写一块题头。--docx-template 保留单位 Word 文件的样式和页面设置。

幻灯片

单独一行 --- 开始下一张幻灯片。一个 # 是标题页，## 是内容页，??? 之后是演讲者备注。
