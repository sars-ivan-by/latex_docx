latex-docx

Build a DOCX, PDF, or PowerPoint file from Markdown or LaTeX. An agent picks the template, the language, and the slide layout. A scientific article is one template, not the whole tool.

Install

macOS and Linux:

pip install "latex-docx[omml,pptx]"

Windows

Install Python 3.9 or newer and tick “Add python.exe to PATH”. PDF also needs Microsoft Word. In PowerShell:

py -m pip install "latex-docx[omml,pptx,win]"

The win extra installs pywin32, which is how Word writes the PDF. In cmd, use python instead of py when Python is already on PATH.

From a git checkout:

py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install -e ".[omml,pptx,win,dev]"

If PowerShell refuses Activate.ps1, run Set-ExecutionPolicy -Scope CurrentUser RemoteSigned once. In cmd the activator is .venv\Scripts\activate.bat.

omml writes formulas as Word math. pptx is required for slides. On Linux, PDF is written by LibreOffice (soffice), and the page can differ from Word.

Command line

latex-docx article.tex -o out_article.docx
latex-docx notes.md -o out_notes.docx --lang en --pdf
latex-docx slides.md -o out_slides.pptx --pptx-template org.pptx
latex-docx --diff-docx out_base.docx out_edited.docx -o out_changes.md

Library

from latex_docx import convert, docx_to_pdf, markdown_to_pptx

convert("notes.md", "out_notes.docx", lang="en")
docx_to_pdf("out_notes.docx")
markdown_to_pptx("slides.md", "out_slides.pptx", template="org.pptx")

The organization .pptx supplies slide size, theme, and layouts. Slides already in that file are not copied. Pass title_layout and content_layout when the layout names differ from the defaults.

lang is ru (the default) or en. Template tdj still prints the Russian front matter and then the English front matter. Templates plain and article print one block. --docx-template keeps an organization's Word styles.
