latex-docx

Convert a scientific LaTeX article to Word, a Markdown note to the same DOCX, or Markdown to PowerPoint. PDF is saved by Microsoft Word from that DOCX.

Install

pip install "latex-docx[omml,pptx]"

omml writes formulas as Word math. pptx is required for slides. PDF needs Word on the machine. Windows also needs pywin32.

Command line

latex-docx article.tex -o out_article.docx
latex-docx notes.md -o out_notes.docx --pdf
latex-docx slides.md -o out_slides.pptx --pptx-template org.pptx
latex-docx --diff-docx out_base.docx out_edited.docx -o out_changes.md

Library

from latex_docx import convert, docx_to_pdf, markdown_to_pptx

convert("notes.md", "out_notes.docx")
docx_to_pdf("out_notes.docx")
markdown_to_pptx("slides.md", "out_slides.pptx", template="org.pptx")

The organization .pptx supplies slide size, theme, and layouts. Slides already in that file are not copied. Pass title_layout and content_layout when the layout names differ from the defaults.

TD-J captions inside the article DOCX stay in Russian (Аннотация, Рис., Таблица). The tools themselves are in English.

Slides

A line --- starts the next slide. One # is the title slide, ## is a content slide, and ??? starts speaker notes.
